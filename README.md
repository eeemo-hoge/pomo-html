# pomo-html

A browser-based Japanese Pomodoro timer built with plain HTML, CSS, and JavaScript. No Python, backend, or build step is required.

## Use the app

After GitHub Pages is enabled, open <https://eeemo-hoge.github.io/pomo-html/>. The site is served over HTTPS for free.

To enable deployment once, open the repository's **Settings → Pages** and select **GitHub Actions** as the build and deployment source. The workflow deploys the site automatically whenever changes are pushed to `main`.

You can also download or clone the repository and open `index.html` directly in a modern browser. No local server is required.

The timer continues to track elapsed time while its tab is in the background. Allow browser audio after pressing Start to hear notification sounds.
