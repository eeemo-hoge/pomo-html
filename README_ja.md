# pomo-html

HTML・CSS・JavaScriptだけで作られた、日本語のポモドーロタイマーです。Python、バックエンド、ビルド手順は不要です。

## アプリを使う

GitHub Pagesを有効にすると、<https://eeemo-hoge.github.io/pomo-html/> から無料のHTTPSで利用できます。

最初にリポジトリの **Settings → Pages** を開き、ビルドとデプロイのソースとして **GitHub Actions** を選択してください。その後は `main` ブランチへの変更時に自動でデプロイされます。

ローカルで使う場合は、リポジトリをダウンロードまたはクローンし、`index.html` をブラウザーで直接開いてください。ローカルサーバーは必要ありません。

## 使い方

1. 作業時間、休憩時間、セッション数などを設定します。
2. 「開始」を押すとタイマーが始まります。
3. 作業中は「今すぐ休憩(追加休憩)」で追加休憩に切り替えられます。休憩中は「作業に戻る」で作業を再開できます。
4. 「中止」で設定画面に戻ります。

タブがバックグラウンドにある間も経過時間を計測します。通知音を使うには、開始ボタンを押した後にブラウザーの音声を許可してください。
